06

Guia de estilo e estados

Cores com nome, letras com reserva, todos os estados de botão, campo e link.

Cores

{{ c.nome }} {{ c.hex }} · {{ c.cr }} {{ c.uso }}
Títulos e números Fraunces 700 · R$ 48.320 'Fraunces', Georgia, 'Times New Roman', serif
Texto e interface Nunito 400, 600, 700 e 800. Base 17px. 'Nunito', system-ui, -apple-system, 'Segoe UI', Roboto, sans-serif

Entrega em WOFF2, subconjunto latino, só os pesos listados, font-display: swap. Meta: as duas famílias juntas abaixo de 300 KB. As reservas têm métricas próximas, então o texto não pula quando a fonte carrega.

Botões

Altura 48px (56px no celular para Entrar). O foco usa contorno musgo sólido de 3px, afastado 3px, visível sobre qualquer sombra.
{{ n }}
{{ b.nome }}{{ b.uso }}

Desativado não depende só da cor: o texto ao lado diz o que falta (“Preencha o e-mail para continuar”). Carregando mantém a largura, troca o texto por “Aguarde…” ou pela ação em andamento (“Entrando…”), marca aria-busy e bloqueia o segundo toque. Mouse em cima só existe em @media (hover:hover).

Campos

Campos sem marcação são obrigatórios. Os que não são levam “(opcional)” no rótulo. Sem asterisco.
{{ f.estado }} {{ f.msg }}

Erro: borda siena de 2px, ícone e texto abaixo do campo, ligado por aria-describedby, com aria-invalid. A mensagem aparece ao sair do campo ou ao enviar, nunca a cada letra. O exemplo de formato fica no texto de ajuda, não só no placeholder.

Links

Link em texto sempre sublinhado. Visitado (argila escura, 7:1) só em links de conteúdo, como guias e relatórios; o menu usa o estado ativo com aria-current.
